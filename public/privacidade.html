Política de Privacidade

Esta página descreve como a BluePartner trata os dados coletados no portal de validação de licenças Microsoft.

Dados coletados

  • Dados de identificação do pedido, como pedidoId, token e revenda.
  • Dados informados pelo usuário ou integrados ao fluxo, como CNPJ e informações de conta Microsoft.
  • Dados técnicos de acesso, como IP, user-agent, data e hora da ação.

Finalidade

  • Validar o aceite do cliente e registrar a operação.
  • Atender exigências de segurança, auditoria e rastreabilidade.
  • Suportar a autenticação Microsoft Entra ID e o fluxo de autorização das licenças.

Armazenamento e retenção

  • Os registros ficam armazenados no banco do sistema enquanto forem necessários para operação, auditoria e suporte.
  • O acesso é restrito a perfis administrativos e superadministrativos autorizados.
  • Logs podem ser mantidos por período compatível com obrigações legais, contratuais e de segurança.
Se houver uma política interna de retenção específica, ela deve substituir este texto.

Compartilhamento

  • Os dados podem ser compartilhados com serviços Microsoft necessários para autenticação e autorização.
  • O fluxo também pode encaminhar o usuário ao distribuidor indicado no pedido, apenas para continuidade da parceria.

Contato

Para dúvidas sobre privacidade e tratamento de dados, fale com a equipe BluePartner pelo canal oficial de atendimento.
